# Contributing

Thanks for helping. This is a small project maintained on a best-effort basis.

- **Bugs and compatibility reports:** open an issue using the templates. Never include hostnames, usernames, IP
  addresses, serial numbers, passwords or logs that contain personal paths.
- **Security problems:** do not open a public issue, see [SECURITY.md](SECURITY.md).
- **Pull requests:** keep them small and focused. By submitting one you agree your contribution is licensed under
  the Apache License 2.0, the same as this project (section 5 of the license).
- **Code from upstream:** changes to unmodified XSecureLock code are best sent to
  [upstream](https://github.com/google/xsecurelock), which requires its own contributor license agreement.
- Keep the original copyright and license headers; mark files you modify with a short notice.
- Test with `timeout 30 ~/.local/bin/sbs-glasslock` and describe the environment you tested on.
